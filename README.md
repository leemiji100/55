과제 목표
이 과제를 마친 후, 학습자는 아래를 스스로 설명할 수 있어야 한다.

텍스트 프롬프트의 구성 요소(스타일, 레이아웃, 색상 등)가 결과물에 미치는 영향을 설명할 수 있다.



AI 생성 이미지의 문제점(텍스트 깨짐, 부자연스러운 요소)을 식별하고 수정하는 방법을 설명할 수 있다.



AI 생성 이미지의 일관성을 유지하기 위한 방법(시드 고정, 이미지 레퍼런스 등)을 설명할 수 있다.



기획 → 이미지 생성 → 후가공 → 프로토타입으로 이어지는 AI 협업 워크플로우를 설명할 수 있다.



기능 요구 사항
다음 요구사항을 모두 만족해야 한다.

이미지 생성
이미지 생성 AI 도구(네이토 ,제미나이, 챗gpt)를 1개 이상 사용한다

최소 3개 이상의 화면(메인 페이지, 목록 페이지, 상세 페이지 등)을 생성한다.

생성된 UI 디자인은 모바일(9:16) 또는 데스크탑(16:9)의 일반적인 화면 비율을 준수한다.



프롬프트 최적화
프롬프트 개선 과정(초안 → 수정 → 최종)을 문서로 기록한다.

초안(1) : 캐릭터 프롬프트 : 앱으로 다마고치를 만들건데 비주얼 적으로 예쁜 여자아이 (10세정도) 2d 도트평 캐릭터를 생성해줘. 
옷은 드레스에 여러가지 장신구를 차고 있지만 너무 지나치지 않고 적당히 어울리고게 부탁해. 귀엽고 깜찍해서 키우고 싶게 만들어줘

수정(2): ui / ux 생성 프롬프트 : 최대한 단순하고 사용자 편의성을 최우선으로 하는 ui / ux 디자인의 다마고치 앱을 만들고 싶어. 홈화면 ( 캐릭터가 있는 화면 )
/ 놀아주기 / 옷입히기 / 여행보내기 / 다마고치 설정 메뉴를 넣을거야. ui 화면을 이미지로 생성해줘. 최적의 ux로 잘 만들어줘. 설정 창에는 캐릭터와 대화하는
방식으로 만들어줘. 첨부한 이미지와 맞는 이미지 ui / ux로 만들어줘. 픽셀 도트 캐릭터이기 때문에 이것에 맞는 ui도 도트 픽셀로 만들어줘



각 수정 단계에서 변경한 이유와 결과 차이를 기록한다


1차 시안(달걀)에서 2차 시안(공주)으로 수정한 이유

1차 시안은 새싹이 달린 달걀 캐릭터를 중심으로 한 심플한 다마고치 콘셉트였습니다. 캐릭터가 귀엽고 직관적이라는 장점은 있었지만, 전체적으로 콘텐츠의 확장성과 사용자의 몰입을 이끌어내기에는 한계가 있었습니다. 이에 따라 단순히 캐릭터를 돌보는 게임이 아니라 사용자가 애정을 가지고 지속적으로 성장시키고 꾸밀 수 있는 육성 게임의 방향으로 콘셉트를 발전시켰습니다.

1. 캐릭터 성장의 재미를 강화하기 위해

1차 시안에서는 캐릭터의 변화 요소가 제한적이어서 장기간 플레이할 동기가 다소 부족했습니다. 이를 보완하기 위해 2차 시안에서는 공주 캐릭터를 중심으로 의상과 액세서리를 변경하고 성장 과정을 시각적으로 표현할 수 있도록 수정했습니다. 사용자는 캐릭터를 키우면서 다양한 모습을 수집하고 꾸미는 재미를 경험할 수 있습니다.

2. 타깃 사용자의 취향을 반영하기 위해

공주풍 일러스트와 파스텔톤 디자인은 캐릭터 꾸미기와 아바타 게임을 선호하는 사용자층에게 친숙한 분위기를 제공합니다. 특히 리본, 드레스, 인형, 핑크 계열의 인테리어를 활용하여 감성적인 분위기를 조성하고, 사용자에게 애착을 형성할 수 있도록 디자인 방향을 변경했습니다.

3. 게임의 목적성을 명확하게 하기 위해

1차 시안은 상태 관리 중심의 UI 비중이 컸다면, 2차 시안에서는 간식 주기, 놀아주기, 목욕하기, 잠재우기처럼 육성 행동을 중심으로 구성하여 사용자가 무엇을 해야 하는지 직관적으로 이해할 수 있도록 개선했습니다. 또한 의상 변경과 여행 등의 콘텐츠를 추가하여 게임 플레이의 목표를 더욱 다양하게 만들었습니다.

4. 화면의 몰입감을 높이기 위해

기존 시안은 여백이 많고 캐릭터가 중앙에만 배치되어 다소 단조로운 느낌이 있었습니다. 2차 시안에서는 방 안의 가구와 소품을 배치하여 실제 캐릭터가 생활하는 공간처럼 연출했습니다. 이를 통해 게임의 세계관을 강화하고 화면을 더욱 풍성하게 구성했습니다.

5. UI의 통일성과 완성도를 높이기 위해

1차 시안은 메뉴마다 컬러가 분산되어 있었지만, 2차 시안에서는 핑크와 크림 계열을 메인 컬러로 통일하여 전체적인 디자인의 일관성을 높였습니다. 또한 픽셀풍 아이콘과 UI 요소를 적용하여 레트로 게임 감성을 더하고, 캐릭터와 인터페이스가 하나의 콘셉트로 자연스럽게 연결되도록 개선했습니다.

6. 플레이 동기를 강화하기 위해

기존에는 상태 수치 확인이 주요 기능이었다면, 수정된 시안에서는 출석(Day), 코인, 의상 수집, 여행 콘텐츠 등을 추가하여 반복 플레이에 대한 보상을 제공하도록 설계했습니다. 이러한 시스템은 사용자가 꾸준히 접속하고 캐릭터를 성장시키려는 동기를 높여줍니다. 그리고 또한 캐릭터를 스스로만들어 몰입감을 주었으며 이를 가장 큰 장점으로 생각합니다.







Figma 등 디자인 도구를 사용하여 생성된 이미지를 배치한다.
화면 간 이동 흐름을 나타내는 클릭 가능 영역(Hotspot) 또는 화면 전환을 표시한다.
